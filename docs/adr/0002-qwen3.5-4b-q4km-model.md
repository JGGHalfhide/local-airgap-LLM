# 0002. Qwen3.5 4B (Q4_K_M) as the model

Status: accepted (Week 1, 11/21)

## Context

The model has to be openly licensed, run at usable speed on CPU, fit in an
airgap VM that shares a 28 GiB host with the build VM, and serve Phase 3
agents: tool calling, structured output, and prompts that carry several
thousand tokens of retrieved context.

Five candidates, all Apache-2.0 GGUF files from official publishers, were
benchmarked on the host with llama.cpp v1.0.0 (benchmarks/README.md).
At 8 threads, tokens/s:

| Model | File | pp512 | tg128 | pp512 @4k ctx | tg128 @4k ctx | Peak RSS (bench) |
|---|---|---|---|---|---|---|
| Granite 4.2 3B Q4_K_M | 2.1 GiB | 201 | 25.9 | 118 | 15.0 | 3.7 GiB |
| Qwen3.5 4B Q4_K_M | 2.8 GiB | 145 | 16.6 | 124 | 15.0 | 4.6 GiB |
| Qwen3.5 4B Q8_0 | 4.2 GiB | 123 | 11.7 | 107 | 11.0 | 4.4 GiB |
| Granite 4.2 8B Q4_K_M | 5.0 GiB | 83 | 11.0 | 56 | 7.7 | 8.8 GiB |
| Ministral 3 8B Q4_K_M | 4.8 GiB | 88 | 11.5 | 62 | 8.2 | 8.0 GiB |

- All five passed the five tool-calling and structured-output cases
  (scripts/toolcall-check.py), so that check did not separate them.
- Qwen3.5 4B loses about 10% of its speed at 4k tokens of context; the
  others lose 30-40%. At 4k context it matches Granite 3B on generation and
  is faster on prompt processing, which dominates time to first token for
  retrieval-heavy agent requests.
- The 8B models are about half the speed and twice the memory, for no
  measured gain on the checks above.
- Q8_0 is about 30% slower than Q4_K_M.
- llama-server with the chosen settings (ADR 0001) peaks at 3.9 GiB at 8k
  context and 4.6 GiB at 32k context.

## Decision

Use Qwen3.5 4B at Q4_K_M:

- Source: `ggml-org/Qwen3.5-4B-GGUF`, revision
  `8d43d974efc48399cb58957ad49c8b26bf5a109c`, file `Qwen3.5-4B-Q4_K_M.gguf`
- SHA-256: `217002fa8008ef4fc6d548353a3aebef055a96e6ff8e0e2c0953ef8254a89c14`
- Base model: `Qwen/Qwen3.5-4B` (revision
  `851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a`)
- License: Apache-2.0 (GGUF repo and base model)

Granite 4.2 3B Q4_K_M (Apache-2.0) is the fallback if Qwen3.5 4B shows
problems in Weeks 2-3. Quality beyond the tool-calling checks is evaluated
in Phase 3 with a task-specific set.
