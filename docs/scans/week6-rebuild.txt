## Found and fixed
1. Image tags move: the platform-lab quickstart published
   postgres:17.12-alpine3.24 by tag; Docker Hub had rebuilt it, so the
   pushed digest (f9cf3e1f...) was not the pinned one (a77aa70e...) and db-0
   could not pull. Both READMEs now publish every image as tag@digest, and
   list all of them (KEDA's six, the llama.cpp runtime and alpine were
   missing).
2. On the airgapped cluster make smoke printed ALL PASSED but exited 2:
   platform-lab's registry_env_cleanup (`[[ -n "$x" ]] && rm ...`) returns
   1 when registry_env never ran, and the EXIT trap made that the script's
   status. Fixed in platform-lab scripts/lib.sh (if instead of &&),
   platform-lab e57978f (with the README image list).
3. The airgap runbook started the airgap VM with virsh; after a full
   teardown it has to be created with make rehearsal. Runbook updated.
4. make smoke run straight after a previous run failed: its namespace was
   still terminating. smoke-test.sh now waits for it first.
